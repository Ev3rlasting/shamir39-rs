# Changelog

## 0.2.0 - 2026-08-01

- Expose a library API for creating and recovering shares.
- Introduce the self-describing `shamir39-v1` share format.
- Reject mixed, duplicate, malformed, and insufficient shares.
- Preserve leading-zero entropy with fixed-width encoding.
- Add crates.io metadata, release checks, and coverage for invalid inputs.
